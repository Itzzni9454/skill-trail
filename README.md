## 🛠️ Installation Guide (Windows)

Follow these steps carefully. Take your time – there's no rush.

### Step 1: Download the ZIP file

1. Open your web browser and go to: [https://github.com/Itzzni9454/skill-trail](https://github.com/Itzzni9454/skill-trail)
2. Click the green **"Code"** button near the top-right of the page
3. Select **"Download ZIP"** from the dropdown menu
4. Wait for the download to complete (it may take a few minutes depending on your internet speed)

**Tip:** Your browser will usually save the file to your **"Downloads"** folder.

### Step 2: Extract the ZIP file

Now you need to "unzip" (extract) the downloaded file:

1. Navigate to your **Downloads** folder
2. Find the file named **skill-trail-main.zip** (or similar)
3. **Right-click** on the file
4. Select **"Extract All..."** from the menu
5. In the window that appears, click **"Extract"**
6. Wait for the extraction to finish – you'll see a new folder appear named **skill-trail-main**

### Step 3: Run skill-trail

You're almost there! Now:

1. Open the **skill-trail-main** folder you just extracted
2. Look for a file named **start.bat** or **run-skill-trail.bat** (or a file named **skill-trail.exe**)
3. **Double-click** that file
4. A black window (command prompt) may flash – this is normal
5. After a few seconds, your browser will open automatically with skill-trail ready to use

**Note:** If you see a blue Windows SmartScreen warning, click **"More info"** then **"Run anyway"**. This is normal for self-hosted apps and only appears because it's not from the Microsoft Store.

### Step 4: Start learning

🎉 Congratulations! You're now viewing skill-trail in your browser. Everything runs locally on your machine – your data never leaves your computer.

## 🔧 Troubleshooting Common Issues

| Problem | Solution |
|---------|----------|
| **"Windows protected your PC" message** | Click "More info" → "Run anyway". This happens because the app isn't code-signed. It's safe. |
| **Browser doesn't open automatically** | Go to your browser and type `http://localhost:3000` and press Enter |
| **Port already in use** | Close the black command window, restart your computer, and try again |
| **Can't find the start file** | Make sure you extracted the ZIP completely. Look for files with .bat or .exe extension |
| **Nothing happens when I double-click** | Right-click the .bat file and select "Run as administrator" |
